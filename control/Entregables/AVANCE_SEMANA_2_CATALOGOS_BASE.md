# Avance Semana 2 - Catalogos Base

Proyecto: IO Group Web - Control  
Semana: 2  
Objetivo semanal: dejar revisados los catalogos base con evidencia visible para jefatura.  
Estado: Siguiente

## Resumen Para Jefatura

Esta semana se revisaran los modulos base que alimentan el resto del sistema: clientes, sedes, empresas, vehiculos, plantas, empleados y usuarios. El resultado esperado es que cada catalogo pueda abrirse, registrar informacion, editarse y mostrarse con datos de prueba o datos reales.

## Entregables De La Semana

| Modulo | Resultado Esperado | Estado |
|---|---|---|
| Clientes / Sedes | Listado, registro, edicion y cartilla revisados | Pendiente |
| Empresas | Confirmar si sera visible en menu o modulo interno | Pendiente |
| Vehiculos | Listado, registro y edicion revisados | Pendiente |
| Plantas | Listado, registro y edicion revisados | Pendiente |
| Empleados | Listado, registro y edicion revisados | Pendiente |
| Usuarios | Listado, registro, roles y permisos revisados | Pendiente |

## Checklist Operativo

- [ ] Probar apertura de cada pantalla de catalogo.
- [ ] Validar que los listados carguen.
- [ ] Crear o simular un registro por catalogo.
- [ ] Editar un registro por catalogo.
- [ ] Validar mensajes de error o exito.
- [ ] Revisar permisos visibles para usuarios.
- [ ] Registrar errores encontrados.
- [ ] Agregar capturas al cierre semanal.

## Bloqueos Potenciales

| Bloqueo | Impacto | Alternativa |
|---|---|---|
| Falta de datos reales | No se valida informacion final de clientes o empleados | Usar datos de prueba y reemplazar cuando se entreguen datos reales |
| Falta de accesos al servidor | No se puede validar en ambiente productivo | Validar localmente y documentar pendiente de deploy |
| Definicion de Empresas | Puede quedar visible o interno | Definir durante revision semanal |
